# Por qué elegí el tipo de Licencia MIT?
He elegido la Licencia MIT para esta actividad porque me parece necesario eliminar cualquier barrera legal que pudiera limitar su uso. Busco simplicidad y transparencia, además de que pienso que el conocimiento debe ser de libre y fácil acceso, yo mismo soy testigo de eso, al aprender casi todo lo que sé de este modo. Es prioridad poder dar al mismo sistema que nos dio tanto.
